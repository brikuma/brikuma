# Product roadmap

ID: BRK-ROAD-001

Owner/scope: Integration root

Status: Specified

Baseline: frontend execution brief 1.1.0 / consolidated product v0.0.3, 2026-09-24.

| Milestone                                      | Current status                            | Boundary                                                                                                                         |
| ---------------------------------------------- | ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Repository ownership and source baseline       | Private remotes and submodules registered | Independent histories and linked canonical policy; remote protection remains plan-blocked.                                       |
| Frontend POC                                   | Implemented; pinned by project root       | Static routes, local core/3D edits, sample instructions/inventory, truthful previews.                                            |
| Delivery hardening                             | Local checks measured; limits documented  | Accessibility, build, performance, hooks, architecture and browser evidence; untested devices and field metrics remain explicit. |
| Backend contracts and persistence              | Deferred                                  | Requires a separate assignment; no invented API now.                                                                             |
| AI assistance and references                   | Deferred                                  | No model/provider, OCR or arbitrary generation in POC.                                                                           |
| Collaboration and community services           | Deferred                                  | No notifications, invitations, presence or publishing now.                                                                       |
| Marketplace and billing                        | Deferred                                  | No purchases, entitlement engine or protected digital delivery now.                                                              |
| Physical validation and instruction generation | Deferred                                  | Engineering claims require independently scoped methods/evidence.                                                                |

This is a scope map, not a release-date promise. See [frontend delivery plan](../brikuma-frontend/docs/delivery/PLAN.md), [context](PROJECT_CONTEXT.md) and [decisions](DECISIONS.md).

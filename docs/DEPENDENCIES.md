## Installation and scripts

`.npmrc` uses `ignore-scripts=true` and exact engine checks. Initial installation is `npm install --ignore-scripts`; reproducible clones use `npm ci --ignore-scripts`. Review lifecycle scripts before explicitly invoking the root-owned `npm run prepare`, which runs the verified local Husky binary only. No arbitrary package script or global installation is approved.

Husky is a hook runner; lint-staged checks formatting without writing; commitlint runs only on the commit message. Hooks call repository scripts and never install/browse/download. Raw command evidence belongs in ignored `artifacts/quality/`. The audit covers the full production/development tree; there are no runtime production packages here. Relevant unresolved high/critical advisories block delivery. No force-fix or blanket ignore is allowed.

Root local installation completed with `npm install --ignore-scripts`: 81 packages added, audit reported zero known vulnerabilities. A subsequent full `npm audit --audit-level=high --json` returned zero findings across the resolved production/development tree. Seven dependencies declare source-repository `prepare` scripts (cliui, cosmiconfig, get-caller-file, tinyexec, y18n, yargs, yargs-parser); none ran during installation and no install/postinstall scripts were found. The root-owned explicit `npm run prepare` installed Husky after sandbox permission for repository-local `.git/config`; `git config --local --get core.hooksPath` returned `.husky/_`.

The disposable fresh-clone hook test passed (about 4.9 seconds), exercising actual wrappers, missing review rejection, malformed message rejection, unstaged-input rejection without data loss, and a valid reviewed atomic commit. It reuses already-installed dependencies only inside its temporary test fixture; it is not proof of a fresh network install or a product shared-runtime design. Related: [quality](QUALITY_GATES.md), [review](ai/REVIEW_POLICY.md), [repositories](REPOSITORIES.md).

ID: BRK-PROD-001

BRIKUMA is an independent product concept for designing models made of interlocking construction bricks. The long-term vision includes references, assisted design, multiple systems, inventories, instructions, collaboration, community and digital discovery. The current assignment implements only a frontend POC.

Free-form creation is an equal entry point alongside curated examples. Visual language, construction approach, intended function and constraints remain distinct. Mechanical construction is not a color theme. Future AI includes useful free access and paid exploration; here it is a clearly labeled pre-authored interface preview.

Collision, connection, stability, build-order and physical testing are separate concepts. None is replaced with an invented aggregate safety score. Revisions, quantities and instruction compatibility must be internally consistent where computed.

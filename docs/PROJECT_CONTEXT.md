# Product context

ID: BRK-PROD-001

Owner/scope: Integration root

Status: Specified

Baseline: frontend execution brief 1.1.0 / consolidated product v0.0.3, 2026-09-24.

BRIKUMA is an independent product concept for designing models made of interlocking construction bricks. The long-term vision includes references, assisted design, multiple systems, inventories, instructions, collaboration, community and digital discovery. The current assignment implements only a frontend POC.

Free-form creation is an equal entry point alongside curated examples. Visual language, construction approach, intended function and constraints remain distinct. Mechanical construction is not a color theme. Future AI includes useful free access and paid exploration; here it is a clearly labeled pre-authored interface preview.

Collision, connection, stability, build-order and physical testing are separate concepts. None is replaced with an invented aggregate safety score. Revisions, quantities and instruction compatibility must be internally consistent where computed.

The authoritative implementation brief is user prompt revision 1.1.0, consolidated baseline v0.0.3, research date 2026-09-24. Three original Word documents were not supplied and have not been reviewed. No original feature-ID mapping is asserted. The specified FORMA image was not present at `references/forma-editor-reference.png` during initial inspection. The supplied shared ChatGPT link was initially unavailable and subsequently inspected during the studio revision. See [source register](SOURCES.md).

The initial design direction described a warm ivory/graphite/deep-teal studio, isometric courtyard model, brief/constraints panel, project/check inspector and restrained assistant composer. The owner's later review supersedes that palette and interface direction; current implementation decisions are maintained by the frontend. Use BRIKUMA, never the provisional FORMA brand. Do not imitate official LEGO packaging or imply affiliation, certification or submission eligibility.

The owner's later 2026-09-24 review rejects the initial visual and modeling experience and explicitly prioritizes both detailed 3D presentation and useful manual building. Three newly supplied shared concept-image references and the re-supplied original Masseria reference were visually inspected in Chrome, together with relevant accessible discussion in the authorized “Lego Builder” ChatGPT project. The [frontend provenance record](../brikuma-frontend/docs/references/README.md) states the exact inspection coverage and remaining source limitations. This supplements the initial verbal design direction without changing the frontend-only boundary.
